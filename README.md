# StudyStart JYU: web services group task

This is our group repository for Task 2 of the SOA and Cloud Computing course (TIES4560) at the University of Jyväskylä, September 2025. Our team made parts of "StudyStart JYU", a helper service for new international students. Every member worked in their own folder.

| Folder | Author | What it is |
|---|---|---|
| `Remon/` | Rakibul Hasan Remon (me) | A Python Flask client for the Dropbox REST API with the POST operations: OAuth token exchange, file upload, folder creation and account info |
| `mushfiq/` | Mushfiqul Islam | A Flask Dropbox client that lists files and folders in a dashboard |
| `Task2-2/` | churight | A combined Flask backend and HTML frontend for Task 2.2 |
| `marta/` | Marta Klakovych | SOAP services for profiles and documents (Java) |
| `Sayeem/` | Mohammad Sayeem Sadat Hossain | A SOAP university management system (Java) |

I created this repository and wrote the code in `Remon/`. To run my part, see `Remon/README.md`. It needs your own Dropbox app key and secret in a `.env` file, which is not added here.
